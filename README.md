# Students Day — вход (проверка билетов)

Сайт для людей на входе: вводите номер билета (или имя) и нажимаете «Впустить».
Все устройства видят отметки сразу. Повторный вход по тому же билету подсвечивается красным
с временем первого входа. Если двое одновременно отметят один билет, пройдёт только один (транзакция в базе).

## Возможности
- счётчик «зашли / осталось» с прогресс-баром;
- поиск по номеру и имени, фильтры «Все / Не зашли / Зашли»;
- Enter в поле поиска сразу отмечает билет по точному номеру;
- отмена ошибочной отметки;
- «Настройка»: создание билетов по диапазону, импорт списка `номер;имя`, название входа, выгрузка CSV, сброс отметок.

## Запуск
Используется тот же проект Firebase, что и у рассадки (данные лежат в ветке `tickets`).
1. Firebase → Realtime Database → **Rules**: вставьте `database.rules.json` и нажмите **Publish**.
2. Загрузите папку в НОВЫЙ репозиторий GitHub и подключите его к новому проекту Vercel (Framework Preset: *Other*).
3. Откройте сайт → **Настройка** → «Создать / обновить билеты 1–327» (распределение по институтам — в `RANGES` в `app.js`).

Локальная проверка: `npx serve .` (модули не работают через `file://`).

## Безопасность
Правила открытые: любой, у кого есть ссылка, может менять данные. Для закрытия включите в Firebase
Authentication → Anonymous, замените `true` на `"auth != null"` в правилах и поставьте `anonymousAuth: true` в `config.js`.
